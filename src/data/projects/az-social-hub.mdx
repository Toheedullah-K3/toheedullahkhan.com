# AZ Social Networking Hub

A feature-rich social network marketplace built with PHP Laravel and PostgreSQL, empowering users to connect, trade services & products, manage interactive profiles, and process transactions.

## Overview

AZ Social Networking Hub is an integrated social network and digital marketplace platform designed for AZ Pvt Ltd. It bridges community interaction with e-commerce, allowing users to connect with peers, showcase offerings, publish social posts, and buy or sell products within a unified digital ecosystem.

## Key Features

- **Social Networking Feed**: User-generated content sharing, posts, comments, and media feeds
- **Digital Marketplace**: Multi-vendor listing for products and services with category filtering
- **User Profiles & Dashboards**: Customizable public profiles, order history, and account settings
- **Role-Based Access Control**: Granular permissions for buyers, sellers, and platform administrators
- **PostgreSQL Database Backend**: High-performance data modeling for transactions and social graph connections
- **Responsive Interface**: Mobile-friendly, adaptive layouts for smooth browsing across all devices

## Technologies Used

- **Backend Framework**: PHP with Laravel framework for secure, enterprise-grade MVC architecture
- **Database**: PostgreSQL for robust relational data management, transactions, and indexing
- **Frontend & Styling**: HTML5, CSS3, JavaScript, and Bootstrap for dynamic UI components
- **Deployment**: Configured and deployed on production server infrastructure

## Project Highlights

- Developed robust Laravel backend modules for social interaction and marketplace e-commerce
- Designed scalable PostgreSQL schema with optimized query speeds and foreign key constraints
- Built clean user interface components ensuring seamless cross-device compatibility
- Delivered high reliability for user authentication, transaction handling, and media management
