# SkyCars.pk

An automotive portal and car rental platform built on WordPress, featuring technical & on-page SEO optimization, Google Search Console indexing, PageSpeed performance tuning, and managed deployment on Hostinger.

## Overview

SkyCars.pk is a premier car rental and automotive services platform in Pakistan. As the Website Manager & SEO Specialist, I managed the entire digital lifecycle—from WordPress theme customization and content strategy to technical SEO, Google Search Console indexation, Google Analytics monitoring, and speed optimization on Hostinger servers.

## Key Features

- **SEO & Search Visibility**: Optimized on-page metadata, structured JSON-LD schema markup, and target keyword rankings for car rental services.
- **Google Search Console Integration**: Configured automated XML sitemaps, monitored crawl errors, indexation status, and search query performance.
- **Google PageSpeed & Performance Tuning**: Enhanced Core Web Vitals, asset minification, image compression, and server-level caching on Hostinger.
- **WordPress Customization**: Tailored WordPress theme structures, custom page layouts, and user-friendly vehicle booking forms.
- **Traffic Analytics**: Set up Google Analytics tracking for monitoring organic traffic growth, bounce rates, and conversion goals.
- **Managed Hostinger Hosting**: Managed DNS routing, SSL certificate installation, database optimization, and server uptime.

## Technologies Used

- **CMS Platform**: WordPress for dynamic content and car fleet management
- **SEO & Indexing**: Google Search Console, Google Analytics, Schema Markup, On-Page SEO
- **Speed & Optimization**: Google PageSpeed Insights, LiteSpeed/WP Rocket Caching, Image Compression
- **Languages & Customization**: PHP, HTML5, CSS3, JavaScript
- **Hosting & Infrastructure**: Hostinger Cloud/Shared Server environment with SSL security

## Project Highlights

- Increased organic search rankings and impression counts in Google Search Console
- Achieved fast load speeds on Google PageSpeed Insights through caching and image optimization
- Maintained 99.9% website uptime and security on Hostinger servers
- Delivered a clean, conversion-focused mobile experience for car rental clients
