# Ian Darrah Yoga & Wellness

A personal branding and yoga training website built for Ian Darrah (Miami & Peru based yoga master), featuring workshop schedules, retreat bookings, client testimonials, and reliable hosting on Bluehost.

## Overview

Ian Darrah is an internationally recognized yoga master and wellness trainer based in Miami and Peru. This project delivered a serene, elegant, and functional web platform that highlights Ian's training philosophy, upcoming retreat schedules in Peru, international workshops, and client testimonials.

## Key Features

- **Serene Brand Identity**: Calming visual design aligned with mindfulness, movement, and wellness
- **Retreat & Workshop Showcase**: Detailed pages for international yoga retreats in Peru and training programs in Miami
- **Media & Gallery Section**: Integrated photo galleries and video demonstrations of yoga practices
- **Client Testimonials**: Dedicated sections highlighting student experiences and transformational reviews
- **Bluehost Infrastructure**: Managed web hosting setup, security, and DNS maintenance on Bluehost
- **Fully Responsive**: Optimized for seamless viewing on mobile phones, tablets, and desktops

## Technologies Used

- **CMS**: WordPress for flexible content updating and event management
- **Languages**: PHP, HTML5, CSS3, JavaScript for custom styling and interactivity
- **Hosting**: Deployed and configured on Bluehost hosting environment

## Project Highlights

- Designed and developed custom WordPress website for a global yoga instructor
- Configured hosting, domain, and security protocols on Bluehost
- Built clear call-to-action sections for retreat inquiries and private bookings
- Optimized image loading for high-resolution photography without compromising speed
