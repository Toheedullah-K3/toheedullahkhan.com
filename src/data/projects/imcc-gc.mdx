# IMCC GC

A complete commercial & civil construction company website featuring custom design, WordPress CMS integration, service showcases, project portfolios, and high-performance hosting deployment on Hostinger.

## Overview

IMCC GC is the official digital presence for International Multi-Construct Company (IMCC), a leading construction and engineering contractor. The project encompassed the entire lifecycle—from initial wireframing and UI/UX design in Figma, through custom WordPress development, to server setup and domain hosting on Hostinger.

## Key Features

- **Custom UI/UX Design**: Modern, corporate aesthetic reflecting trust, engineering excellence, and reliability
- **Service Portfolio**: Structured presentation of civil, commercial, and structural engineering services
- **Interactive Project Showcase**: High-resolution gallery and case studies of completed construction projects
- **Client Inquiry & Quotation Forms**: Customized lead generation and contact channels
- **Hostinger Hosting Setup**: Managed web hosting deployment, SSL certification, and custom domain mapping
- **Mobile Responsive Layout**: Fully responsive experience optimized for desktop, tablet, and mobile browsers

## Technologies Used

- **CMS Platform**: WordPress for dynamic content management and easy content updates
- **Design & Mockups**: Figma for layout prototyping and color scheme selection
- **Languages**: PHP, HTML5, CSS3, JavaScript for theme customization
- **Hosting & Infrastructure**: Managed Hostinger server deployment with SSL security

## Project Highlights

- End-to-end delivery: Initial design concept to live production site
- Self-managed hosting configuration on Hostinger with 99.9% uptime and fast page speeds
- Custom responsive WordPress theme tailored specifically to construction industry needs
- Optimized for Search Engines (SEO) and lead conversion
